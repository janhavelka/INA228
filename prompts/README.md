# INA228 Historical Prompt Archive

The files under `prompts/ina228_industry_hardening_prompt_chunks/` are the
historical AI-coder prompts used to drive the industry-readiness hardening work.
They are retained as an audit trail and are not current task instructions,
release notes, public API documentation, or hardware validation evidence.

Use the final docs in `docs/` for current status:

- `docs/INA228_INDUSTRY_HARDENING_FINAL_REPORT.md`
- `docs/INA228_RELEASE_CHECKLIST.md`
- `docs/INA228_HARDWARE_VALIDATION_MATRIX.md`
- `docs/INA228_RELEASE_PREP_REPORT.md`
- `docs/INA228_ESPIDF_BUILD_PROOF_REPORT.md`

Completed prompts should remain intact unless a maintainer deliberately moves
them into a future archive structure and updates links.
